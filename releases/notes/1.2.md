# TRAE FLOW 1.2

TRAE FLOW 1.2 正式版本发布。本次更新修复了全局快捷键注册与语言切换显示两项关键问题，并调整了默认配置以提升开箱体验。

## 修复

- **全局快捷键注册不生效**：`@Published` 在 `willSet` 时刻发送事件，此时 `wrappedValue` 尚未更新，导致 `refreshRegistrations` 读到旧值，录制 / 复原快捷键均不生效。为 `openActiveSessionShortcut` / `openSessionListShortcut` / `leftFeatureQuickExpandShortcut` 三个订阅链路添加 `.receive(on: RunLoop.main)`，将 sink 调度到下一 runloop tick，确保读取到落地后的新值
- **语言切换中英混杂**：设置页「检查更新」区域的文字通过 `AppLocalization.string` 本地化，在应用 / 系统语言切换时会出现中英混杂显示。更新区域文字统一固定为中文，避免本地化查找导致显示异常

## 变更

- 鼠标离开自动收起 Flow 岛（`autoCollapseOnLeave`）默认值从「开启」改为「关闭」，避免鼠标偶然离开触发区即收起面板，影响连续操作体验
