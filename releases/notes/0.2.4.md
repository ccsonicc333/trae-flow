# TRAE FLOW 0.2.4

## 亮点

- 新增内置「AI 热搜」功能：默认启用并排在第一位，开箱即用，无需任何配置即可在灵动岛查看 AI 领域热点
- 左侧功能开箱即用策略：音乐、中转站默认启用，配合 AI 热搜组成默认功能区，新用户安装后立刻有可玩内容
- 首次启动自动安装 TRAE Hooks：不再延后到首次欢迎向导，安装后即可接收 TRAE IDE 事件
- 「TRAE Flow 自定义功能演示」预设改为默认启用，展示 JS Bridge 四区块交互能力

## 变更

- `LeftFeatureStore` 新增 `aihot` 内置功能（webURL 指向 aihot.virxact.com），默认 sortOrder=0 启用
- 内置功能 sortOrder 重排：AI 热搜(0) / 音乐(1) / 中转站(2) / NewsNow(trailingBase) / Mineradio(trailingBase+1)
- 新增「末尾内置功能」机制：NewsNow / Mineradio 始终排在用户自定义功能之后，sortOrder ≥ 1000
- `CustomAreaStore` 演示预设重命名为「TRAE Flow 自定义功能演示」并改为默认启用
- `HookInstaller` 首次启动改为直接执行 `performFirstRunDefaultInstall()`，移除已废弃的 onboarding pending 标记
- 默认展开面板宽度从 500 调整为 630
- README 更新：Hooks 启用提示截图、三条主线文案优化、变体配置表格排版修正

## 说明

- 本次发版重点优化开箱即用体验：新用户安装后默认有 AI 热搜 + 音乐 + 中转站 + 演示四个可用功能，且 TRAE Hooks 自动安装无需手动配置
