# TRAE FLOW 0.2.3

## 亮点

- 自定义功能「在 TRAE 中打开」改为变体选择菜单：从原来固定使用 TRAE CN 升级为列出全部四个 TRAE 变体（TRAE / TRAE CN / TRAE WORK / TRAE WORK CN），用户可自由选择任一变体打开工作区

## 变更

- `TraeVariant` 新增 `isInstalled` 双路检测（标准安装路径 + LaunchServices 回退）与 `installedCases` 已安装变体列表
- `TraeSessionLauncher.openWorkspace` 增强：IDE 系列走 URL Scheme 工作区协议；SOLO/WORK 系列改用 `NSWorkspace.open([URL], withApplicationAt:)` 等价于 `open -a` 打开目录；最终回退仅激活应用
- 设置页 `.customArea` 功能行的固定按钮替换为 `openInTraeMenu` 变体选择 Menu
- `CustomArea.defaultVariant` 字段保留用于向后兼容，不再被设置 UI 读取
- AGENTS.md 更新 jump-back-to-IDE 与左侧功能说明

## 说明

- 本次发版让用户可以灵活选择任一已安装的 TRAE 变体打开自定义功能工作区，不再受限于固定变体
