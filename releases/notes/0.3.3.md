# TRAE FLOW 0.3.3

## 修复

- 修复 Flow 岛窗口被菜单栏图标隐藏类应用（iBar / Bartender / Ice 等）遮罩窗口拦截点击的问题：窗口层级从 `.mainMenu + 3` 提升到 `.popUpMenu + 50`（rawValue 151），盖过 menu bar hider 的 overlay，同时仍低于 `.screenSaver` 不影响锁屏
- 修复同一 cwd 下不同 TRAE 变体并发会话被 `SessionStore` 误合并的问题（Spec: `dual-variant-concurrent-session-key`）：
  - `HookPayloadMapper` 在 hook 未传 `session_id` 回退到 cwd 时，拼入 `__CFBundleIdentifier` 解析出的变体标识，sessionId 变为 `provider:variant:cwd`，避免四个变体在同一目录下生成相同 key
  - `SessionStore.appendSession` 去重逻辑增加变体判断：仅当两会话解析到同一变体（或都无法解析）时才清理旧会话，不同变体的并发会话不再互相清除
- 修复自定义 HTML 区域未开启「允许请求外部接口」时 `fetch` / `XMLHttpRequest` / `navigator.sendBeacon` 仍可发起网络请求的问题：注入 `networkBlockScript`（atDocumentStart）从 JS 层源头拦截，仅放行 `file:` / `trae-flow-local:` 本地资源与 JS Bridge 消息通道

## 变更

- 鼠标悬停自动展开 Flow 岛默认值从「开启」改为「关闭」，避免鼠标路过触发区误触展开；用户仍可在设置中开启
- 演示页区块 2 升级：GitHub API JSON 改为随机猫咪图片，并增加多源 fallback 链（The Cat API → Cat as a Service → The Dog API 兜底）+ 图片代理 fallback（images.weserv.nl，保证国内网络可用）；3 源 × 2 加载方式共 6 种尝试
- 演示页 HTML 模板版本化（`defaultDemoHTMLVersion`）：模板升级时老用户启动会自动覆盖刷新 `trae-flow-demo/index.html`（用户已删除则不重建）
- 体验用例文档文案调整：移除「鼠标悬浮」相关描述，统一为「点击展开」

## 说明

- 本次为 0.3.x 系列的 patch 版本，修复窗口层级、多变体并发会话、自定义区域网络权限三项关键问题，并升级演示页图片加载能力
