# TRAE FLOW 0.3.1

## 修复

- 修复左侧功能切换栏拖拽排序失效问题：`Button` 包装会消费 mouseDown 事件导致 `.onDrag` 几乎无法识别拖拽手势，改用普通 View + `.onTapGesture` 处理点击，让 `.onDrag` / `.onDrop` 能正常接管鼠标拖拽
- 紧凑态音乐功能从「仅图标」恢复为渲染 `MusicCompactView`（18pt 封面 + 截断标题），与文档描述一致

## 变更

- 文案统一：将「精灵表」调整为「宠物表」（README、宠物设置页提示词模板）
- `AGENTS.md` 同步紧凑态音乐渲染说明

## 说明

- 本次为 0.3.x 系列的 patch 版本，聚焦修复 v0.3 引入的拖拽回归与紧凑态音乐显示问题
