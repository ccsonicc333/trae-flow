# TRAE FLOW 0.3

## 亮点

- 新增 `traeFlowCollapse` JS Bridge：自定义 HTML 区域可通过 `window.webkit.messageHandlers.traeFlowCollapse.postMessage({})` 主动收起 Flow 岛展开面板，配合提示推送可实现「推送后自动收起」的流畅交互
- 内置「TRAE Flow 自定义功能演示」重新设计：三区块结构 + 喝水提醒（集成 Flow 岛推送 + 可设定时提醒）

## 变更

- `CustomAreaWebView` 注册 `traeFlowCollapse` message handler，Coordinator 转发为 `traeFlowCollapseLeftExpanded` 通知
- `NotchView` 监听收起通知，新增 `collapseLeftExpandedPanel()`，仅对 docked 展开态的 `customExpanded` 生效，不影响分离态
- 演示页 HTML 重构：原四区块（提示 / 接口 / 计数器 / 监控）合并为三区块（喝水提醒 / 接口 / 监控）
  - 喝水提醒卡片集成 Flow 岛推送：「喝一杯水 +1」计数（localStorage 持久化）、「发送提醒」测试按钮推送「已喝水 N 杯」并自动收起展开面板、「启动定时」按 1–240 分钟间隔自动推送喝水提醒
  - 定时器不收起面板，保持 WebView 存活使定时器持续
- `ReleaseNotesWindowView` 版本号显示加 `fixedSize` 防止截断
- `.gitignore` 新增 `default.profraw` / `*.profraw` 忽略 LLVM profiling 输出
- README 删除一段重复描述

## 说明

- 本次发版标志着 0.3.x 系列开始：重点强化自定义 HTML 区域与 Flow 岛的交互能力，JS Bridge 从单向提示扩展为双向联动（推送 + 收起）
- 喝水提醒演示页是「自定义 HTML 区域 + JS Bridge」的最佳实践示例，可作为用户开发自己功能区的参考
