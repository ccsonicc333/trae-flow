# TRAE FLOW 1.1

TRAE FLOW 1.1 正式版本发布。本次更新聚焦于自定义 HTML 区域视觉体验打磨，让用户嵌入的网页内容与 Flow 岛深色主题更协调。

## 新功能

- **自定义区域深色滚动条**：为本地自定义 HTML 区域注入深色半透明滚动条样式（`color-scheme: dark` + 8px 宽度 + rgba(255,255,255,0.22) thumb），避免 WebKit 默认浅色系统滚动条与 Flow 岛深色主题不协调。仅对 `.localArea` 生效，不影响 `.remoteURL` / `.mineradio` 等远程内容
