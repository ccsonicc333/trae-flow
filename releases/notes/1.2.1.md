# TRAE FLOW 1.2.1

TRAE FLOW 1.2.1 发布。本次更新为内置演示页新增「在 TRAE CN 中编辑」入口，并优化首次展开尺寸，让自定义功能的创建与迭代更顺畅。

## 新功能

- **`traeFlowOpenInTrae` JS Bridge**：自定义 HTML 区域新增「在 TRAE 中打开编辑」消息通道。HTML 端通过 `window.webkit.messageHandlers.traeFlowOpenInTrae.postMessage({ variant: "trae-cn" })` 触发，应用以当前区域目录为工作区在指定 TRAE 变体（默认 TRAE CN，支持 tra-e / trae-cn / trae-work / trae-work-cn）中打开，便于用户直接编辑 HTML 源文件。仅 `.localArea` 源有效，网络拦截脚本已放行该通道
- **演示页编辑入口卡片**：内置「TRAE Flow 自定义功能演示」页 Hero 上方新增紫色渐变 CTA 卡片「想要快速实现自定义功能？去 TRAE 编辑」，点击调用 `traeFlowOpenInTrae` Bridge 在 TRAE CN 中打开演示页目录，引导用户直接修改 HTML 源文件
- **演示页默认展开尺寸**：演示页内容较多（Hero + CTA + 三个区块），首次展开默认尺寸从全局回退值调整为 720×850，保证首次打开即可完整呈现，避免内容被裁剪需要手动拖拽。已手动调整过尺寸的用户不受影响（通过 `backfillExpandedSizeIfNil` 仅回填 nil 值）
