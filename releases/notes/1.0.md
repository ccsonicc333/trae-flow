# TRAE FLOW 1.0

经过多个 beta 版本迭代，TRAE FLOW 迎来首个正式发布版本。本次更新聚焦于交互体验打磨与多项关键问题修复，为日常编码陪伴场景提供稳定可靠的基础。

## 新功能

- **Dock 图标显示开关**：新增「在 Dock 中显示图标」设置项（设置 → 通用）。关闭后应用切换为 accessory 策略，仅在菜单栏运行，不再出现在 Dock 中；开启时恢复为 regular 策略。测试构建不受影响
- **用户主动展开突破全屏隐藏限制**：通过快捷键或点击触发的展开（`openReason == .click`）在全屏应用下不再被强制收起，让用户在全屏 IDE / 浏览器中也能随时呼出 Flow 岛查看任务或使用左侧功能。被动展开（hover / notification / boot）仍受全屏隐藏抑制，避免误触

## 修复

- 修复宠物已分离到桌面时 docked Flow 岛无法点击展开的问题：`mouseDown` 进入拖拽分离跟踪后，`mouseUp` 的 detached guard 拦截了短按展开逻辑。现在仅 docked 状态下触发拖拽分离手势，分离态下点击直接展开面板
- 修复宠物拖拽分离手势进行中误切换到中转站的问题：拖拽期间不再响应文件拖拽 hover，避免 dragPasteboard 残留 URL 导致误切换
