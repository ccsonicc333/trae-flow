# TRAE FLOW 0.3.2

## 修复

- 修复自定义 HTML 区域图标未同步到 `LeftFeature.customIconName` 的 bug：创建 / 编辑 / 启动迁移三个路径都会同步 `CustomArea.iconName`，使 `FeatureIconView(feature:)` 能正确渲染文字 / 图片图标，不再回退到默认 `globe` SF Symbol
  - `CustomAreaStore.addArea` / `addAreaWithAutoGeneratedDirectory` / `addTestHTMLArea` 联动调用 `appendCustomAreaFeature` 时传入 `iconName`
  - `SettingsWindowView` 编辑保存回调调用 `setCustomIconName` 同步图标
  - 新增 `LeftFeatureStore.syncCustomAreaIconNames`，启动时幂等补齐老数据（仅填充 nil，不覆盖已设置图标）

## 变更

- 默认 Flow 岛宽度从 320 调整为 380，紧凑态展示更多信息
- 新增「TRAE Flow 体验用例」文档（`docs/experience-cases/`），覆盖 Hook 安装、双变体任务、自定义功能、桌面宠物 detach、中转站、网页嵌入、音乐控制等场景的图文演示
- 体验用例文档侧边栏目录滚动优化：增加边缘容差与节流，避免 sticky + 浮点在边界附近反复触发滚动抖动

## 说明

- 本次为 0.3.x 系列的 patch 版本，修复自定义区域图标显示问题并补充体验用例文档
